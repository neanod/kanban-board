⚡ TaskBoard API Documentation

Complete guide to authenticating, querying, creating tasks, managing the 4 Kanban workflow states, and uploading files programmatically.

1. Authentication & API Keys

All API requests must be authenticated. The API supports two header formats: 

X-API-Key: kb_username_your_secret_token_here
# OR
Authorization: Bearer kb_username_your_secret_token_here
How to issue API Keys:
  • Via Website: Click on 🔑 API Keys in the top navigation bar, give the key a label, and click Generate Key.
  • Via Telegram Bot: Open chat with @tasksboard67bot, click 🔑 API Keys, and select ➕ Generate New API Key.
  • Via API: Existing authenticated clients can call POST /api/v1/keys.

2. Security & Rate Limiting

To defend against DDoS, brute-force, and exploits:

MechanismPolicyResponse on Violation
Global API Rate Limit 120 requests / minute per client IP 429 Too Many Requests
Login Brute-Force Shield Max 5 login attempts / minute per IP 429 Too Many Requests
File Upload Limit Max 25 MB per attachment 413 Payload Too Large
Key Storage Salted SHA-256 hash in SQLite with WAL mode Raw key cannot be recovered if DB leaked

3. REST API Endpoints

GET /api/v1/stats

Get task count summary across all 4 columns.

curl -H "X-API-Key: YOUR_KEY" https://your-domain.com:8445/api/v1/stats
Response:
{
  "open": 4,
  "in_progress": 2,
  "review": 1,
  "completed": 12,
  "total": 19
}
GET /api/v1/tasks

List tasks. Optional query filters: status (open, in_progress, review, completed) and assignee.

curl -H "X-API-Key: YOUR_KEY" "https://your-domain.com:8445/api/v1/tasks?status=open"
POST /api/v1/tasks

Create a new task in open status.

curl -X POST https://your-domain.com:8445/api/v1/tasks \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"title": "Refactor database indexing", "description": "Add index to task_id"}'
GET /api/v1/tasks/{task_id}

Get full task details including attachments and comments history.

curl -H "X-API-Key: YOUR_KEY" https://your-domain.com:8445/api/v1/tasks/1
DELETE /api/v1/tasks/{task_id}

Permanently delete a task, its attachments, and audit history.

curl -X DELETE https://your-domain.com:8445/api/v1/tasks/1 \
  -H "X-API-Key: YOUR_KEY"
POST /api/v1/tasks/{task_id}/claim

Claim task into In Progress. The authenticated user becomes the assignee.

curl -X POST https://your-domain.com:8445/api/v1/tasks/1/claim \
  -H "X-API-Key: YOUR_KEY"
POST /api/v1/tasks/{task_id}/release

Release an In Progress task back to Open.

curl -X POST https://your-domain.com:8445/api/v1/tasks/1/release \
  -H "X-API-Key: YOUR_KEY"
POST /api/v1/tasks/{task_id}/submit-review

Submit task for verification (moves to Under Review).

curl -X POST https://your-domain.com:8445/api/v1/tasks/1/submit-review \
  -H "X-API-Key: YOUR_KEY"
POST /api/v1/tasks/{task_id}/approve

Approve task in review and mark as Completed. Records the authenticated user as reviewed_by.

curl -X POST https://your-domain.com:8445/api/v1/tasks/1/approve \
  -H "X-API-Key: YOUR_KEY"
POST /api/v1/tasks/{task_id}/reject

Reject a task in review and return it to Open with a required comment.

curl -X POST https://your-domain.com:8445/api/v1/tasks/1/reject \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"comment": "Unit test coverage is below 80%. Please write tests for auth module."}'
POST /api/v1/tasks/{task_id}/attachments

Upload a file or image attachment (multipart/form-data, max 25MB).

curl -X POST https://your-domain.com:8445/api/v1/tasks/1/attachments \
  -H "X-API-Key: YOUR_KEY" \
  -F "file=@/path/to/screenshot.png"
GET /api/v1/attachments/{attachment_id}

Download or view an attachment file.

curl -H "X-API-Key: YOUR_KEY" -O https://your-domain.com:8445/api/v1/attachments/att_id_here
POST /api/v1/keys

Generate a new API key.

curl -X POST https://your-domain.com:8445/api/v1/keys \
  -H "X-API-Key: YOUR_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name": "CI/CD Pipeline"}'

4. Code Examples

Python (httpx / requests)

import httpx

API_KEY = "kb_dmitry_your_api_key_here"
BASE_URL = "https://your-domain.com:8445"

headers = {"X-API-Key": API_KEY}

# 1. Create a task
resp = httpx.post(f"{BASE_URL}/api/v1/tasks", headers=headers, json={
    "title": "Automated security patch",
    "description": "Triggered by security auditor."
})
task = resp.json()["task"]
task_id = task["id"]
print(f"Created Task #{task_id}")

# 2. Claim task
httpx.post(f"{BASE_URL}/api/v1/tasks/{task_id}/claim", headers=headers)

# 3. Submit for review
httpx.post(f"{BASE_URL}/api/v1/tasks/{task_id}/submit-review", headers=headers)

# 4. Upload an attachment
with open("report.pdf", "rb") as f:
    httpx.post(f"{BASE_URL}/api/v1/tasks/{task_id}/attachments",
               headers=headers, files={"file": f})

JavaScript / Node.js (fetch)

const API_KEY = "kb_dmitry_your_api_key_here";
const BASE_URL = "https://your-domain.com:8445";

async function run() {
  const headers = {
    "X-API-Key": API_KEY,
    "Content-Type": "application/json"
  };

  // Get board stats
  const statsRes = await fetch(`${BASE_URL}/api/v1/stats`, { headers });
  console.log("Board stats:", await statsRes.json());
}
run();
